# raorla.github.io

Portfolio of Orlando Rasolofoniaina, AI Engineer. Live at https://raorla.github.io

Built with Next.js (static export), React Three Fiber, GSAP and Lenis. A WebGL field made of characters from my own agents' source code morphs as you scroll.

```bash
npm install
npm run dev     # http://localhost:3100
npm run build   # static export in out/
```

Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.
